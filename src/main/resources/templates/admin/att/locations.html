围栏判定规则

· 员工端打卡时提交浏览器定位的经纬度、客户端 IP 与 WiFi SSID；后端按 Haversine 公式计算与启用地点的球面距离。
· 距离 ≤ 配置半径，或 IP 命中白名单，或 WiFi 匹配，则允许打卡；三者皆不满足直接拒绝并记录拒绝原因。
· 地点可按考勤组绑定：不勾选任何考勤组表示对全公司生效；勾选后仅对该组成员生效。
· 未配置任何启用地点时，打卡一律拒绝，避免围栏静默失效。
